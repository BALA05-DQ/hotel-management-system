# 🏨 Hotel Management & Booking System

A simple and user-friendly Hotel Management and Booking web application built using React.js, Redux, Node.js, Express.js, and PostgreSQL.

This project allows users to view available hotels, search and filter hotels based on price, view detailed hotel information with location, and allows administrators to add, edit, and delete hotel details.

---

## 📌 About the Project

The main idea of this project is to create a simple Single Page Application (SPA) for managing and viewing hotel information.

The application has two main sections:

- **User Side** – Users can search hotels, filter them by price, view hotel details, and check the hotel location on a map.
- **Admin Side** – Admin can add new hotels, update existing hotel details, and delete hotels.

The frontend communicates with the backend through REST APIs, and all hotel information is stored in PostgreSQL.

---

## ✨ Features

### 👤 User Features

- View available hotels
- Search hotels by title
- Filter hotels using minimum and maximum price
- Pagination for hotel listings
- View hotel image, name, description, and price
- Click on a hotel to view complete details
- View hotel location using latitude and longitude
- Responsive and simple user interface

### 🔐 Admin Features

- View all hotels
- Add a new hotel
- Upload hotel images
- Preview image before submitting
- Edit existing hotel details
- Update hotel image if required
- Delete hotels
- Confirmation before deleting a hotel
- Success message after deletion
